# Project Requirements from D2L
Your project will be a console-based application written in C++ that demonstrates concepts covered in this course. You want to choose something that is not trivial, while also not being overly ambitious. With that said, types of programs suitable for a capstone project in this course include (but are not limited to):

- A rudimentary information system that maintains items such as recipes, books, shop inventories, media titles, fantasy sports teams, employee information, student records, etc.
- A limited text-based interactive fiction or adventure game
- Programs that track things such as workouts, to-do items, calendar items, etc.

Your program will need to include classes to define one or more abstract data types in a meaningful way. In addition, your program should include at least four of the following concepts:

- Abstract classes
- Class templates
- Inheritance
- Polymorphism
- Overloaded operators (a minimum of three)
- Sorting (using an algorithm you implement)
- Data structures covered in this course that you will implement from scratch (arrays, structs, and vectors will not satisfy this requirement):
   - Lists
   - Stacks
   - Queues
   - Maps/Hash Tables
- Recursion (aside from that used in sorting algorithms)
